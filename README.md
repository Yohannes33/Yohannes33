# Hi, I'm Yohannes

I build the software that sits between people and the systems they depend on, and increasingly between those systems and AI.

I work across the stack in Python and TypeScript, mostly where systems meet: identity, realtime, mapping and third-party services wired into existing products, securely and end to end. I build AI-native, with coding agents in my daily workflow and code review, tests and CI keeping the output honest.

Right now I'm focused on applying LLMs and agents to real business systems, and on the engineering that makes them dependable.

### What I work with

- **Languages:** Python, TypeScript, SQL
- **Backend:** FastAPI, Frappe / ERPNext, Node.js, REST APIs, role-based access control
- **Frontend:** Next.js, React, Tailwind CSS, TanStack Query, Zod
- **Data and platform:** PostgreSQL, Supabase (Auth, RLS, Realtime, Edge Functions), GitHub Actions, Vercel
- **AI and optimisation:** Whisper speech-to-text, Hugging Face Transformers, Google OR-Tools, Claude Code
